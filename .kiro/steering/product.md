# Product — Szkolenia Glocksklep

Polish firearms training scheduling for Glocksklep / Glockacci.

- Users browse courses and dates, register (email/password, email link, Google), enroll, join waitlists, view proforma invoices.
- Admins manage courses, dates, participants (paid/cash), dictionaries (places, instructors, tags), CMS (descriptions, FAQ, regulamin), billing data.
- Public brand UI via `@stayfrosty/ui` (tactical hard-shadow look). Admin is operational but still uses `@ui`.
- UI copy in Polish; code identifiers in English.
- Domain: `szkolenia.glocksklep.pl`
